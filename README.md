# Лабораторная работа № 1

Прямой расчёт внутренней баллистики для варианта № 17 выполнен моделью
`ozvb_lagrange` из `pyballistics 1.2.1`.

Запуск из корня проекта:

```text
uv sync --frozen
uv run python main.py
```

Программа не требует интерактивного ввода, выводит результаты всех
проверочных точек и пересоздаёт пять рисунков в каталоге `figures/`.
Описание расчёта и результатов приведено в `report.md` и `report.pdf`, ответы
на замечания повторной сдачи — в `changes.md`.
