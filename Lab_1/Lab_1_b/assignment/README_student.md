# Материалы лабораторной работы № 1

Начните с `01_assignment.pdf`. Точные правила оформления вынесены в `02_gost_profile.md`, а распределение баллов — в `03_grading_rubric.md`.

Последовательность работы:

1. найдите свою строку в `variants/variants.csv` и расшифруйте её по `variants/legend.md`;
2. скопируйте `student_template/` в каталог `lab1_<Фамилия>/`;
3. реализуйте свой расчёт и замените все шаблонные поля и рисунок;
4. проверьте запуск `uv sync --frozen` и `uv run python main.py`;
5. соберите `report.pdf` выбранным инструментом;
6. отправьте один ZIP-архив по правилам раздела 11 задания;
7. после назначения чужой работы заполните `04_peer_review_form.md`.

Не используйте § 3.3 методического пособия как эталон для этой функции и не подключайте оптимизатор: оба действия находятся вне постановки ЛР № 1.
