# Таблица вариантов: обозначения и правила чтения

Файл `variants.csv` — нормализованная запись таблицы 4.1 методического пособия. Десятичный разделитель в CSV — точка.

## Колонки

| Колонка | Смысл |
|---|---|
| `variant` | номер варианта |
| `d_mm` | калибр, мм |
| `q_kg` | масса снаряда, кг |
| `v_pm_m_s` | требуемая дульная скорость при `+20 °C`, м/с |
| `gun_type` | `NR` — нарезное (`НР`), `GS` — гладкоствольное (`ГС`) |
| `model` | `NM` — нульмерная (`НМ`), `KM` — квазиодномерная (`КМ`) |
| `criterion` | `W_pm` — минимизировать; `Z_B1` — максимизировать |
| `p_m_max_MPa` | максимально допустимое среднебаллистическое давление при `+20 °C`, МПа |
| `l_m_max_d` | максимально допустимая длина ведущей части ствола в калибрах |
| `c1_*`, `c2_*` | метрика, температура, знак, предел и единица двух индивидуальных ограничений |

## Метрики индивидуальных ограничений

| Код | Определение | Направление |
|---|---|---|
| `p_mz` | дульное среднебаллистическое давление | `<=` |
| `g_p` | максимальное ускорение снаряда | `<=` |
| `v_pm` | дульная скорость при температуре ограничения | `>=` |
| `eta_e` | относительное положение снаряда в момент полного сгорания заряда | `<=` |
| `psi_p` | относительная масса сгоревшего пороха в момент вылета | `>=` |

Температура указывается в градусах Цельсия: `-50`, `20` или `50`.

## Общие параметры, которых нет в отдельных строках

| Параметр | Нарезное | Гладкоствольное |
|---|---:|---:|
| Давление форсирования `p_0` | 30 МПа | 15 МПа |
| Коэффициент площади `n_S` | 1,04 | 1,00 |
| Площадь канала `S` | `0,26πd²` | `πd²/4` |

Для всех вариантов давление воспламенителя в лабораторной работе принято равным `5 МПа`; воспламенитель — ДРП.

## Примечание к вариантам 33 и 38

В исходной таблице 4.1 записано `g_p+50 = 30000` без напечатанного символа единицы `g`. По определению этого вида ограничения и оформлению остальных строк в нормализованной таблице использовано `30000 g`. Если преподаватель располагает авторской исправленной редакцией методички, это место следует сверить с ней.

## Самопроверка строки варианта

Перед реализацией студент должен переписать строку своего варианта в отчёт и отдельно сформулировать четыре неравенства. Например, не просто `v_pm−50 = 620`, а `v_pm,−50 ≥ 620 м/с`. Это позволяет обнаружить ошибку знака до вычислений.
