# Лекция 2. Python-проект

Модель: одномерное движение тележки с постоянным ускорением. Единицы — СИ.
Это учебный шаблон, не модель реального испытательного стенда.

## Начало работы

Установите uv по официальной инструкции: https://docs.astral.sh/uv/getting-started/installation/
Откройте терминал **в этой папке**, рядом с `pyproject.toml`.

```sh
uv sync --locked
uv run --locked python -m course_motion
uv run --locked python -m unittest discover -s tests -v
```

Ожидаются пять строк расчета и пять успешных тестов.
Python 3.13 выбран как базовая линия занятия; `.python-version` не фиксирует patch-релиз.
`uv` при необходимости может скачать интерпретатор. Для первого запуска могут понадобиться
интернет и доступ к источникам Python / пакетов. `uv.lock` не содержит самих пакетов.

## Блокнот в VS Code

Если Jupyter уже настроен, основной ipynb можно открыть отдельно от этого проекта.
Для работы именно в окружении проекта добавьте ядро:

```sh
uv add --dev ipykernel
```

Откройте **папку проекта** в VS Code. В `notebooks/lecture02.ipynb` выберите
Select Kernel → Python Environments → `.venv` этого проекта.
Проверьте `sys.executable` в первой ячейке. Затем Restart Kernel → Run All.

Для JupyterLab в браузере:

```sh
uv add --dev jupyterlab
uv run jupyter lab
```

Эти команды осознанно изменяют `pyproject.toml` и `uv.lock`. Сохраните оба файла.
В исходном шаблоне сторонних зависимостей времени выполнения нет; lock-файл поэтому короткий.
Готовая инфраструктура Jupyter — отдельное предварительное условие, а не часть Python stdlib.

## Структура

- `src/course_motion/model.py` — модель, без печати при импорте.
- `src/course_motion/__main__.py` — точка запуска, форматирование результата.
- `tests/test_motion.py` — пять проверок на unittest; работают без pytest.
- `notebooks/lecture02.ipynb` — основной конспект лекции.
- `notebooks/report_template.ipynb` — короткий отчет, использующий установленный пакет.
- `pyproject.toml` — описание и сборка пакета.
- `uv.lock` — зафиксированное разрешение зависимостей.

`src` не нужно добавлять в `sys.path`: пакет устанавливается командой `uv sync`.
`uv run python -m course_motion` выполняется **из корня**, не из `src/`.

## pytest — дополнительный вариант

```sh
uv add --dev pytest
uv run pytest -q
```

pytest также умеет запускать этот тестовый файл unittest. Переписывать тесты не нужно.

## Dev Container — необязательный путь

До открытия контейнера убедитесь, что Docker работает и установлено расширение Dev Containers.
Для работы с notebook сначала выполните `uv add --dev ipykernel`, чтобы ядро попало в lock-файл.
Затем Dev Containers: Reopen in Container. Сборка скачивает образы; сама конфигурация
не гарантирует доступность внешних реестров.

Окружение контейнера находится в `/home/vscode/.venvs/course-motion`, а не в примонтированной
`.venv` хоста. Windows- и Linux-окружения нельзя использовать взаимозаменяемо.
После открытия выберите kernel из этого пути. Автоустановка расширений не равна выбору kernel.

Конфигурация статически проверена; запуск Docker в среде подготовки не выполнялся.
Теги образов не закреплены digest; это удобный учебный шаблон, не обещание побитовой воспроизводимости.
Контейнер видит примонтированный исходный код: это не безопасная песочница для произвольного кода LLM.

## Работа с LLM

Попросите сначала прочитать README, модель и тесты. Сформулируйте изменение и проверяемый результат.
Не разрешайте удалять тесты для получения зеленого результата. Самостоятельно объясните формулу,
единицы измерения и один граничный случай. LLM не обязателен для выполнения заданий.
