# ЛР2 — комплект студента

**Тема:** методы оптимизации, SciPy, Optuna и проверяемое использование LLM.

Основная функция: `f=x²+y²+a(2−cos(4x)−cos(4y))`, **a=1**; контроль a=0. Это новая самостоятельная учебная задача, не продолжение баллистической оптимизации. Работа индивидуальная; набор параметров общий для всех.

## Что сдавать
Один ZIP `lab2_<Фамилия>.zip` с исходным uv-проектом, Markdown/PDF, рисунками и сохранёнными журналами. При исправленной сдаче — также changes.md. Команды check/run/report и полный состав описаны в условии. В теме письма обязательно «СМ6»; рекомендуемый шаблон: «СМ6 — ЛР2 — группа — Фамилия».

Срок, адрес отправки и распределение рецензентов сообщает преподаватель. Не включайте в архив .venv, секреты и лишние полные LLM-логи. Не запускайте код других студентов при взаимном ревью.
